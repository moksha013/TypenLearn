# TypenLearn

TypenLearn is a beginner-friendly typing learning web application built to make typing practice more engaging and help users improve their speed, accuracy, and consistency.

The project started as a simple idea for a typing practice website and gradually evolved into a complete V1 with practice, analytics, gamification, and progress visualization.

## Features

### Live WPM

Practice typing while tracking your words per minute in real time.

### Performance Insights

View your typing performance and understand how your speed and accuracy are improving.

### Arcade Mode

A more game-like typing experience designed to make regular practice less repetitive and more engaging.

### Typing Garden

A visual way to represent your progress as you continue learning and practicing.

### Personalized Experience

Users can enter their name to personalize the experience. The name is stored locally in the browser, so it stays available when the application is opened again.
